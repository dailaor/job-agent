# 职来求职助手｜纯前端演示

直接双击 index.html，用 Edge / Chrome 等现代浏览器打开。不需要 Python、Node、数据库、API Key 或后端服务，也可以把全部文件放在任意静态网站托管。

## 可体验的交互

- 左右箭头浏览高推荐岗位，按岗位/公司/地点搜索，筛选同团队体验样本。
- 点“依据”展开证据、待遇细项和待确认问题。
- 在全部岗位查看高推荐、待核实与低推荐岗位，搜索和筛选。
- 记录求职阶段与备注，更新、筛选并刷新恢复。
- 编辑档案与设置，体验匹配向导；“重置演示”恢复初始内容。

所有岗位、公司、薪酬、简历名称和进度均为合成示例。卡片内容与评估为固定演示快照，编辑档案不会运行真实模型或重新生成证据。真实简历解析、采集、情报入库、邮箱检查与投递均不执行，界面会提示演示边界。

进度和配置仅保存在本浏览器的演示专用存储中；若环境禁用存储，会退化为本次打开期间保存。网页不会调用招聘平台、模型或邮箱。无需填写真实联系方式或上传私人简历。

## 文件说明

| 文件 | 用途 |
|---|---|
| index.html | 页面结构与入口，全部引用为相对路径 |
| styles.css、commercial.css | 基础样式与深海蓝主题 |
| app.js | 导航、岗位列表、档案、向导、求职进度等交互 |
| recommendations.js | 推荐卡片、翻页、筛选与证据展开 |
| ui-icons.js、brand-icon.svg | 本地矢量图标 |
| demo-data.js | 可直接阅读的合成 JSON 数据 |
| demo-api.js | 浏览器内模拟接口、存储与重置，不含后端代码 |

均为原生 HTML/CSS/JavaScript，无构建步骤、无外部依赖。运行真实项目时不要加载 demo-data.js / demo-api.js；本包是独立作品展示版，不替代完整版。
